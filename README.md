# RepWise

RepWise is a fitness training and coaching platform designed to connect trainers and clients through structured workout programming, performance tracking, progress analytics, and personalized nutrition insights.

## Status

🚧 Active development

## Tech Stack

### Client
- React
- TypeScript
- Vite
- Tailwind CSS
- Progressive Web App (PWA)

### Backend
- Supabase
- PostgreSQL
- Supabase Auth
- Row Level Security (RLS)

### Server
- Server-side services for privileged operations
- AI nutrition service boundary

## Core Features

- Trainer and client accounts
- Workout programming
- Workout logging
- Exercise library
- Progress tracking
- Body measurements
- Nutrition tracking
- Personalized nutrition assistant
- Trainer client management
- Secure role-based data access
